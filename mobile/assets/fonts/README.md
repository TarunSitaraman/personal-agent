# Heros (TeX Gyre Heros)

Blu's typeface. A free, faithful clone of Helvetica, used because Android ships no Helvetica
and licensing the original for app embedding is paid.

- Source: TeX Gyre, GUST e-foundry — https://www.gust.org.pl/projects/e-foundry/tex-gyre
  (files fetched from CTAN: `fonts/tex-gyre/opentype/texgyreheros-{regular,bold}.otf`)
- Licence: GUST Font License, which permits use, embedding and redistribution. The files are
  unmodified apart from renaming.

Only two weights exist: regular (400) and bold (700). The UI uses bold for all primary text.
